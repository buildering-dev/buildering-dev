# Trading automation in Python

I build trading systems that behave the same in backtest, paper and live, and that fail safely when something breaks:

- **TradingView alerts → broker orders**, with duplicate-alert protection, position checks and protective stops
- **Strategy bots** built to your rules: backtested with real fees and slippage, paper-traded, then live with risk limits and a kill switch
- **Backtest audits** that check for look-ahead bias, missing costs and overfitting, and say plainly whether the edge survives
